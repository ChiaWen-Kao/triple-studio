# triple. studio low-fidelity wireframe

Open `preview.html` to review the mobile and desktop layouts side by side, or open `index.html` for the responsive page.

## Files

- `index.html` — page structure and copy
- `styles.css` — mobile-first responsive layout
- `script.js` — responsive navigation, GSAP Services reveal and form prototype feedback
- `preview.html` — side-by-side 390px and 1280px review board
- `wireframe-mobile-390.png` — mobile first-screen reference
- `wireframe-desktop.png` — desktop first-screen reference

## Wireframe notes

- The dashed Hero canvas is reserved for future 2D scroll animation.
- The contact form submits a booking request only; it does not confirm a meeting time.
- Pricing stays scope-based and does not use example figures.
- Team names, bios and portraits remain placeholders.
